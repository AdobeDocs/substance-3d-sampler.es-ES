# Scripts y desarrollo

Adobe Substance 3D Sampler admite complementos personalizados a través de la API de Sampler Python. Los complementos pueden ser útiles para todos los usuarios de Sampler, desde la automatización de la creación de materiales para grandes bibliotecas de materiales, hasta la realización automática de configuraciones para nuevas instalaciones o la adición de nuevas funciones.

La documentación completa de la API se incluye al instalar Sampler. Puede abrir la documentación de la API en Sampler:

* Utilice Ayuda > Documentación de la API de Python... para abrir la documentación.

* [Administrar scripts y complementos instalados](manage-installed-plugins-and-scripts.md)
* [Crear un complemento con Python y QML](create-a-plugin-with-python-and-qml.md)
* [Crear un script con Python](../scripting-and-development/create-script-with-python/create-a-script-with-python.md)
