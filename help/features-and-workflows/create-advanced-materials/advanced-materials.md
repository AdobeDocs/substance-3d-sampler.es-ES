# Crea materiales avanzados

Con [OpenPBR](../openpbr.md), puedes crear efectos interesantes utilizando canales como [fuzz](fuzz.md), [subsurface](subsurface.md) y [coating](coating.md). Estos canales generalmente solo se utilizan en contextos específicos y pueden funcionar de forma un poco diferente a los canales más utilizados, como la rugosidad o el color base.

- [Fuzz](fuzz.md)
- [Subsuperficie](subsurface.md)
- [Revestimiento](coating.md)
