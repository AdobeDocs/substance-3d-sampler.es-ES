# Informar de un error

Puede informar de errores desde Sampler.

Abra el menú <b>Ayuda </b>y, a continuación, seleccione <b>Informar de un error</b>g:

![](../assets/Bug-report-howto.png.img.png){width="700px"}

Rellene el siguiente formulario:

![](../assets/Bug-report-window.png.img.png){width="400px"}

A continuación, pulsa Enviar. La información que haya introducido se compartirá directamente con el equipo de desarrollo de Sampler.
