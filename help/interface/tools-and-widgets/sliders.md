# Reguladores

![](../../assets/sliders-basic.gif)

Existe la opción de animar uno a varios reguladores. Pulsa **Ctrl** y, al pasar el cursor sobre un regulador, aparecerá un icono de **play** para iniciar la animación.

Puedes pausar la animación pulsando **Ctrl** al pasar el puntero sobre un regulador animado, aparecerá un icono de **pausa** para detener la animación de este regulador.

Si desea pausar todos los reguladores, presione **P**. Para reiniciar, presione **P** de nuevo.
