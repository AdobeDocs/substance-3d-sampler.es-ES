# Acciones rápidas

![](../assets/Quactooltip.png)

Acciones rápidas es un sistema que le permite crear un activo o añadir muchas capas en la pila en unos pocos clics. Utilice Acciones rápidas para crear un activo, crear un proyecto o añadir las capas que necesite a la pila existente.

Puede encontrar acciones rápidas en varios lugares de Sampler:

* [Pantalla de inicio](../interface/the-home-screen.md)
* [Crear nueva ventana](../getting-started/project-management.md)
* [Panel Acción rápida](../interface/panels/quick-actions-panel.md)

| Nombre de acción rápida | Descripción | Capas |
| --- | --- | --- |
| Convertir imagen en material | Cree un material con todos los canales necesarios a partir de una sola imagen. | Imagen de entrada a material AI Equalize |
| Convertir imágenes multiángulo en material | Crea un material combinando fotos de una superficie tomadas desde diferentes ángulos de luz | Multiángulo a material de entrada Ecualizar |
| Importar texturas | Cree un material a partir de mapas de textura. | Entrada |
| Importar imagen | Cree un material vacío y añada una sola imagen como capa. | Entrada |
| Convertir imagen en bordado | Aplique un filtro de procedimiento para que la imagen parezca un parche bordado. | Bordado de entrada |
| Crear material de tela | Cree un material de tela con un filtro de procedimiento. | TejidoDePaño |
| Ajustar imagen | Elija filtros para perfeccionar y preparar una imagen para su uso en un material. | Recorte de entrada Mosaico Brillo/Contraste Tono/Saturación Color reemplazar |
| Crear material vacío | Cree un material sin canales. | Ninguna |

## Cómo utilizar la acción rápida

<b>Desde la pantalla de inicio</b>

Haga clic en una acción rápida

![](../assets/clickquickaction-ezgif.com-video-gif-converter.gif)

o bien arrastra y suelta una imagen en una acción rápida.

![](../assets/dndquickaction-ezgif.com-video-gif-converter.gif)

o bien arrastra y suelta una imagen en una acción rápida.

<b>Desde Crear nuevo</b>

Elija cualquier acción rápida o importe archivos y vea qué acciones rápidas puede utilizar con la entrada

![](../assets/createnew-1.png)

<b>Del Panel Acción Rápida</b>

Haga clic en una acción rápida para añadirla a la pila o crear un nuevo activo en función del tipo de acción rápida:

* <b>Aplicar :</b> Aplica la acción rápida en la pila activa.
* <b>Instalación :</b> Abre la ventana de instalación para preorganizar la acción rápida antes de agregarla a la pila.
* <b>Crear nuevo recurso :</b> Cree un nuevo recurso a partir de la acción rápida seleccionada.
* <b>Crear nuevo proyecto : </b>Cree un nuevo proyecto a partir de la acción rápida seleccionada.
