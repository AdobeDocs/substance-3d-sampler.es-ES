# Panel Ajustes de sombreador

![](../../assets/Shader-settings-panel-gen.png.img.png)

El <b>panel Configuración de Sombreador</b> le permite configurar el modo en que el sombreador procesa sus recursos en la malla en la ventana gráfica 3D.

## Parámetros del material

Los parámetros de material permiten ajustar el procesamiento del material actual por parte del sombreador.

| Nombre del parámetro | Descripción |
| --- | --- |
| Escala normal | Ajuste la intensidad del mapa de normales. |
| Combinar normal y altura | Alterne si el Height y los mapas de normales se combinan en un solo mapa. |
| Nivel de altura | Cambiar el nivel base del height para el desplazamiento. |
| Intensidad de emisión | Ajuste la intensidad de los mapas de emisivo. |
| Dispersión de subsuperficie | Active o desactive la dispersión subsuperficial. |
| Índice de refracción | Ajuste el ángulo en el que la luz se refracta de las superficies. |
| Índice de refracción de capa | Ajuste el ángulo en el que la luz se refracta de la capa superficial. |
| Escala normal de capa | Ajuste la escala normal específicamente para la capa superficial. |
