# Mét. abreviados

Esta página muestra todos los métodos abreviados de teclado disponibles y sus acciones.

## Métodos abreviados globales

| *Acción* | *Windows* | *MacOS* |
| --- | --- | --- |
| Deshacer | Ctrl + Z | ⌘ + Z |
| Rehacer | Ctrl + Mayús + Z | ⌘ + Mayús + Z |
| Guardar | Ctrl + S | ⌘ + S |
| Guardar como | Ctrl + Mayús + S | ⌘ + Mayús + S |
| Exportar | Ctrl + E | ⌘ + E |
| Solo vista 3D | 3 | 3 |
| Solo vista 2D | 2 | 2 |

## Accesos directos de vista 3D

| *Acción* | *Windows* | *MacOS* |
| --- | --- | --- |
| Rotación de cámara | Alt + Ratón izquierdo o Ratón izquierdo | Opción + Ratón izquierdo o Ratón izquierdo |
| Panorámica de cámara | Alt + Centro del ratón o Centro del ratón | Opción + Centro del ratón o Centro del ratón |
| Zoom de cámara | Alt + Ratón a la derecha o Rueda del ratón | Opción + Ratón a la derecha o Rueda del ratón |
| Enfoque | F | F |
| Rotación del entorno | Mayús + Ratón derecha | Mayús + Ratón derecha |
| Visibilidad del entorno | 1 | 1 |
