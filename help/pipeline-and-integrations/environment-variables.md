# Variables de entorno

Esta página muestra variables de entorno que se pueden utilizar para anular el comportamiento predeterminado de la aplicación.

| Variable | Descripción |
| --- | --- |
| **SUBSTANCE\_SAMPLER\_LICENSE** | Valor: Ruta al archivo license.keyAnule la ubicación desde la que la aplicación carga el archivo de licencia.  **Nota:** Las versiones anteriores a la 3.0 utilizan este nombre de variable en su lugar:**SUBSTANCE\_ALCHEMIST\_LICENSE** |
