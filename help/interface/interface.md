# Interfaz

El espacio de trabajo de Sampler se compone de las ventanas gráficas 2D y 3D, las barras laterales izquierda y derecha y una colección de paneles. Cada panel está dedicado a un propósito específico, por lo que los diferentes paneles son útiles durante las diferentes partes del proceso creativo.

## Personalizar el espacio de trabajo

El espacio de trabajo de Sampler es totalmente personalizable, por lo que puede encontrar el diseño que mejor se adapte a sus necesidades. Si alguna vez desea restablecer los paneles al diseño predeterminado, use **Ventana > Restablecer al diseño predeterminado**.

## Reorganización de paneles

Haga clic y arrastre el título de un panel para empezar a moverlo.

Puede acoplar un panel en los bordes de la ventana gráfica u otros paneles: arrastre el panel por el borde en el que desea acoplarlo y aparecerá una guía de resaltado azul. Cuando vea la línea aparecer, suelte el panel para acoplarlo.

## Abrir y cerrar paneles

Utilice la X situada en la parte superior derecha de un panel para cerrarlo. Los paneles cerrados se almacenan en las barras laterales.

Para volver a abrir un panel, haga clic en el icono correspondiente del panel en la barra lateral izquierda o derecha. De este modo, el panel se abrirá temporalmente. Arrastre el panel hacia fuera para mantenerlo abierto de forma permanente.

## Menús de aplicación

La **barra de menú Aplicación** muestra el nombre del proyecto actual. También contiene los menús **Archivo**, **Editar**, **Ventana**, **Ayuda** y **Licencia**.

Use el menú <b>Archivo</b> para crear un nuevo proyecto, abrir un proyecto existente o guardar o exportar el proyecto actual.

Usa el menú <b>Editar</b> para deshacer y rehacer acciones o abre [Preferencias](../interface/preferences/preferences.md).

Use el menú <b>Ventana</b> para restablecer el área de trabajo al diseño predeterminado.

Utilice el menú <b>Ayuda </b>para obtener más información sobre Sampler o para solucionar problemas.

| Bienvenido | Abra la <b>ventana de bienvenida</b> para obtener más información sobre las posibilidades de Sampler. |

| Foro | Abra los foros para participar en la conversación con otros miembros de la comunidad de Substance 3D Sampler o envíe sus propias publicaciones y sugerencias. |
