# Dust

## Presentación

La capa de salpicadura de Dust se utiliza para añadir dust a un material y definir cómo se propaga el dust.

![](../../assets/before-after-1.png)

## Uso

### ¿Cómo se usa?

* Adición de una capa de salpicaduras de Dust
* Establezca la cantidad, el contraste de la extensión y el color para obtener el efecto deseado

#### ¿Cuándo usarlo?

La salpicadura de Dust se puede añadir sobre un material. Puede utilizarlo para suavizar las cavidades o hacer que los diferentes elementos de un material funcionen juntos.

#### Parámetros

* Cantidad de dust: Define la cantidad de dust que agregará
* Profundidad de dust: Definir la profundidad del dust
* Contraste de pliego: Define el enfoque de la transición de dust.
* Evitar la propagación en la Pendiente: Impide que el Dust se propague por la pendiente
