# Panel Proyecto

![](../../assets/Project-panel-gen.png)

Los proyectos de Sampler actúan como paquetes que pueden almacenar varios recursos. El **panel Proyecto** muestra los materiales que componen el proyecto actual.

Los controles situados en la parte superior del panel Proyecto le permiten añadir o administrar materiales en el proyecto actual:

* Usa el botón **Agregar** para abrir el **menú de ajustes preestablecidos de materiales** y agregar un nuevo material a tu proyecto.
* Usa el botón **Duplicar** para duplicar el material seleccionado actualmente.
* Usa el botón **Cambiar nombre** para cambiar el nombre del material seleccionado actualmente.
* Usa el botón **Eliminar** para eliminar el material seleccionado actualmente.

>[!NOTE]
>
> También puede hacer clic con el botón derecho en cualquier material para cambiarle el nombre, eliminarlo o duplicarlo.

Haz clic en uno de tus activos para cargarlos en la **Ventana gráfica** o arrastra un material al **panel Capas** para usarlo en otros materiales.
