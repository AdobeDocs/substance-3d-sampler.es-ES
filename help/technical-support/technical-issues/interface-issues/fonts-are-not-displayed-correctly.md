# Las fuentes no se muestran correctamente

Si estás en Windows 10 Enterprise y usas la función [Bloquear fuentes que no son de confianza](https://docs.microsoft.com/en-us/windows/security/threat-protection/block-untrusted-fonts-in-enterprise), puedes seguir este [tutorial](https://www.tenforums.com/tutorials/139148-exclude-specific-apps-untrusted-font-blocking-windows-10-a.html) para excluir Sampler de la lista de aplicaciones que no son de confianza para el bloqueo de fuentes.
