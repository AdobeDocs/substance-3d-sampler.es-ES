# Gestión de ajustes preestablecidos

Los ajustes preestablecidos le permiten configurar rápidamente el archivo exportado para una aplicación determinada. También puede crear ajustes preestablecidos personalizados para satisfacer sus necesidades si utiliza una canalización que no está cubierta por los ajustes preestablecidos predeterminados.

## Usar ajustes preestablecidos

Los ajustes preestablecidos solo están disponibles al exportar a un archivo de imagen. Al exportar a SBS o SBSAR, no se necesitan ajustes preestablecidos.

Para acceder a Ajustes preestablecidos:

1. Abra la ventana <b>Exportar </b>:
   1. Use el <b>panel Exportar</b> en la <b>barra derecha</b>.
   1. Usar archivo <b> > Exportar como...</b>
   1. Utilizar el método abreviado <b>Ctrl + E.</b>
1. En el lado izquierdo de la ventana <b>Exportar </b>, seleccione <b>Configuración de materiales</b>.
1. Seleccione un formato de imagen (EXR, JPEG, PNG, TARGA, TIFF)
1. Aparecerá la lista Ajuste preestablecido.

![](../../assets/Managing-presets-Dropdown.png.img.png){width="400px"}

Utiliza el menú desplegable Ajustes preestablecidos para seleccionar un ajuste preestablecido o usa el botón <b>Gestionar ajustes preestablecidos </b>situado junto al menú desplegable para administrar los ajustes preestablecidos.

## Administrar ajustes preestablecidos

Utiliza el menú desplegable Ajustes preestablecidos para seleccionar un ajuste preestablecido o usa el botón <b>Gestionar ajustes preestablecidos </b>situado junto al menú desplegable para administrar los ajustes preestablecidos.

## Ajustes preestablecidos predeterminados

![](../../assets/Managing-presets-Window.png.img.png){width="400px"}

Para todos los ajustes preestablecidos predeterminados, puede activarlos o desactivarlos. Si se desactiva un ajuste preestablecido predeterminado, no estará visible en la lista desplegable Ajuste preestablecido .

De forma predeterminada, se activan todos los ajustes preestablecidos.

## Ajustes preestablecidos personalizados

Puede activar o desactivar los ajustes personalizados. Si se desactiva un ajuste preestablecido personalizado, no estará visible en la lista desplegable Ajuste preestablecido .

También puede:

* <b>Cambiar nombre</b>: Cambie el nombre del ajuste preestablecido en la interfaz.
* <b>Reemplazar</b>: Cambie el archivo del ajuste preestablecido a una nueva versión.
* <b>Eliminar</b>: Elimine el ajuste preestablecido.
