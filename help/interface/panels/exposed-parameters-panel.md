# Panel Parámetros expuestos

![](../../assets/ezgif-com-gif-maker-7.gif)

El **Panel Parámetros expuestos** contiene los parámetros expuestos desde el **panel Propiedades.**

Los puntos de color sirven para visualizar a qué capa está conectado el parámetro. Los puntos vacíos indican que el parámetro procede de una capa de mezcla.

![](../../assets/ezgif-com-gif-maker-1.gif)

Hay algunas formas de interactuar con los parámetros expuestos:

| Acciones | Cómo aplicar el |
| --- | --- |
| Desexponer un parámetro | Haga clic con el botón derecho en un parámetro y seleccione &quot;Desexponer&quot;. |
| Editar la etiqueta de un parámetro | Haga clic con el botón derecho en un parámetro y seleccione &quot;Editar&quot;, introduzca la nueva etiqueta. |

Puede interactuar con todos los parámetros como lo haría normalmente con el **panel Propiedades.** Los cambios se reflejarán en la ventana gráfica 3D.
