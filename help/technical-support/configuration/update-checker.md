# Comprobador de actualizaciones

La ventana de actualización indica si hay disponible una nueva versión de Substance Alchemist y muestra también las [Notas de la versión](../../release-notes/release-notes.md) más recientes.

Esta ventana aparece automáticamente durante el inicio de Substance Alchemist si hay una nueva versión disponible para descargar.

Es posible evitar mostrar esta ventana durante el inicio con los siguientes métodos:

* Utilice la opción &quot;No recordarme hasta la siguiente versión&quot; de la ventana para omitir temporalmente la presentación de la ventana hasta la siguiente versión.
* Deshabilite la opción &quot;**Buscar actualizaciones**&quot; en Edición > Preferencias > Buscar actualizaciones
* Usando la línea de comandos **—skip-version-check** No se comprobará si hay una nueva versión de la aplicación disponible cuando se inicie el Substance Alchemist
* Usando una variable de entorno **SUBSTANCE\_ALCHEMIST\_SKIP\_CHECK\_FOR\_UPDATES**:Value 0 o 1 (1 = Deshabilitar comprobación de actualizaciones)

>[!NOTE]
>
> Compatible desde Substance Alchemist 2020.1 (2.1)
