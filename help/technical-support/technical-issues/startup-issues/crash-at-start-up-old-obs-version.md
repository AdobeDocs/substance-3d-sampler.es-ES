# Bloqueo al iniciarse: versión OBS antigua

Es posible que la aplicación se bloquee al iniciarse debido a una versión antigua de [OBS](https://obsproject.com/fr) instalada.

Para resolver este problema, actualice la [versión de OBS](https://obsproject.com/fr/download) o desinstálela.
